01入力をそろえる

UTF-8 XML・最大 8 MiB。元のプロジェクトは変更しません。

ffprobe の chapters・format・streams を含む JSON、または明示的な CSV。最大 4 MiB。

入力形式と制限

ffprobe で -show_chapters -show_format -show_streams -of json を指定して保存します。format と全 stream の start_time は 0 が必要です。

CSV の先頭行は source_seconds,title。時刻は小数秒で、タイトルは 1 行・500 文字以内。最大 10,000 行です。

速度変更・逆再生・プロキシ・入れ子・選択範囲内の未対応トランジション・非ゼロのソース時刻原点はブロックします。XML の外部実体やスクリプトは実行しません。

      マーカーだけを追加したコピー

      元の MLT と同じ場所に保存し、メディアの相対パスを維持してください。ClipChapter の書き出しは、マーカー以外の全バイトを保持します。

      その後 Shotcut で保存すると、Shotcut 自身が一部のメタデータを正規化することがあります。

      章を、編集可能な点へ。

      範囲マーカーや字幕は作りません。既存マーカーと他のクリップ配置はそのままに、選んだ配置へポイントを追加します。

      判断の記録も、一緒に。

      対象配置、元の時刻、丸め差、除外理由、入力と出力の SHA-256 をレシートに保存します。レシートは MLT のダウンロード後に有効になります。
